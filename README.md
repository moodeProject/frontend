# Safe Helmet UI v3

산업 현장 작업자의 안전을 실시간으로 모니터링하고,  
관리자와 근로자 모두가 직관적으로 사용할 수 있도록 구성한 UI 프로젝트입니다.

## 주요 특징

- 관리자 웹 / 근로자 웹 UI 구성
- 작업자 상태 모니터링
- 이상 감지 및 사고·알림 기록
- 헬멧 관리 및 재연결 기능
- 로그인 / 회원정보 수정 / 마이페이지 지원
- 반응형 UI 지원

---

## 레이아웃 정책

- **데스크톱**: 최대 4열
- **태블릿**: 2~3열
- **모바일**: 1열
- **작업자 상태 카드**: 고정 너비 유지

---

## 참고

본 버전은 **작업자 상태 카드의 가독성과 균형감**을 높이기 위해  
레이아웃과 카드 크기를 중점적으로 조정한 업데이트입니다.
